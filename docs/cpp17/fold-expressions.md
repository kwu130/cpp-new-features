# 折叠表达式

折叠表达式用一个运算符归约参数包，取代 C++11 中常见的递归模板和展开技巧。

<!-- example id="cpp17-fold-expressions" std="c++17" file="main.cpp" kind="single" compilers="all" output="10" -->
```cpp
#include <iostream>

template <typename... Values>
auto sum(Values... values) {
    return (values + ... + 0);
}

template <typename... Conditions>
bool all(Conditions... conditions) {
    return (conditions && ...);
}

int main() {
    if (!all(true, 2 < 3, 4 == 4)) {
        return 1;
    }
    std::cout << sum(1, 2, 3, 4) << '\n';
}
```

一元折叠对空参数包只为 `&&`、`||` 和逗号运算符定义了单位值。需要支持空包时，像示例一样提供初始值。对非结合运算符还必须明确左折叠与右折叠的差异。

## 四种折叠形式

折叠可以是一元左折叠 `(... op pack)`、一元右折叠 `(pack op ...)`、二元左折叠 `(init op ... op pack)` 或二元右折叠 `(pack op ... op init)`。最外层括号是语法要求，不能省略。

对于参数 `a, b, c`，左折叠形成 `((a op b) op c)`，右折叠形成 `(a op (b op c))`。加法对普通整数看似无差别，但减法、除法、字符串拼接、流操作以及用户定义运算符可能产生不同结果。

## 空包与单位元

一元 `&&` 空包结果为 `true`，一元 `||` 为 `false`，逗号折叠为空表达式；其他一元运算符没有通用单位元。二元折叠显式给出 `init`，因此可以自然处理空包。示例的求和初始值 0 同时决定某些混合类型表达式的重载路径，应选与领域相符的单位元类型。

## 求值顺序和短路

折叠保留所用运算符的求值规则。`&&`、`||` 会短路，逗号运算符保证顺序；普通算术运算符不要依赖未规定的操作数求值顺序。用折叠执行副作用时，优先选择语义明确的逗号折叠。

## 编译器实例化与成本

前端把折叠展开成普通表达式树，并为参与的重载执行解析。运行时没有“参数包循环对象”，优化器看到的是具体运算链。超长参数包仍会增加语义分析、表达式深度和生成代码体积。

## 工程实践

选择左右方向时写下三元素展开结果进行确认；为空包定义明确语义；避免让运算符重载产生隐藏副作用；错误信息复杂时把单元素操作抽成命名函数，再对调用结果折叠。
